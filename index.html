Featured Project

Smart Energy Monitoring System

An in-progress, low-voltage DC prototype using an ESP32 to collect and display electrical measurements.

In ProgressESP32Arduino IDEOLED

Project goal

Develop a system that measures voltage and current, calculates electrical power, and displays readings on an OLED screen. Current sensing and complete system integration remain under development.

Hardware and tools

  • ESP32 development board
  • SSD1306 128×64 I²C OLED display
  • 0–25 V voltage-sensor module
  • INA219 current/power sensor module
  • Breadboard, jumper wires, and digital multimeter
  • Arduino IDE, Adafruit SSD1306 and GFX libraries

Work completed so far

  • Uploaded and tested code on the ESP32.
  • Initialized the OLED and displayed project text.
  • Read the voltage sensor's analog input and displayed ADC/voltage values.
  • Recorded multimeter readings and worked through wiring and measurement troubleshooting.
  • Introduced the INA219 module; its current readings still need to be verified.

Next milestones

  • Validate voltage readings against a known low-voltage DC input.
  • Test INA219 communication and current measurement separately.
  • Combine verified voltage and current measurements to calculate power.
  • Add energy tracking after the measurement system is reliable.
